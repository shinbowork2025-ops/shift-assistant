# Shift Assistant

店舗PCのブラウザだけで動作する、社内システム登録前のシフト編成支援ツールです。正式な勤怠記録やシフト確定は社内システムで行います。

## 設計方針

- 静的なHTML・CSS・JavaScriptのみで動作
- 入力データはブラウザ内のIndexedDBに保存
- シフトデータを外部サーバーへ送信しない
- JavaScript Object Notation（JSON）で全シフト表をバックアップ・復元
- CSVまたはExcel（`.xlsx`）でマスター読込
- CSVでシフト案を出力
- ビルド処理や外部ライブラリを使わない

## 主な機能

- 複数のシフト表を作成・切替・複製・削除
- シフト表ごとに名称、対象月、更新日時を表示
- 従業員の追加・編集・削除・表示順の変更
- CSV・Excelによる従業員、シフト、残業設定の登録と更新
- 通常シフト・休日区分を収録したExcel見本のダウンロード
- 任意のシフト名、開始時刻、終了時刻の利用
- シフトごとの残業見込み時間
- 従業員ごとの月間固定残業時間
- 月間の残業見込み、固定残業残時間、超過見込みの表示
- 月間シフト案の入力
- 日付を押して1日単位の時間帯チャートを表示
- 従業員ごとの雇用区分（社員・準社員・パート・アルバイト）
- 休憩を除いた15分単位の実配置人数表示（雇用区分別の内訳付き）
- シフト変更後の休憩自動配置
- 休憩の法定基準検証と警告表示
- A4横固定の月間シフト印刷
- 社内システム転記用の日付順一覧
- ワークスペース別のUndo・Redo
- 従業員別の勤務日数・実働時間集計
- IndexedDBへの自動保存
- シフト案のCSV出力
- 全シフト表のJSONバックアップ・復元

## 画面構成

Excelでセルに入力できる程度の操作スキルを前提に、作業の流れが上から順に見えるレイアウトにしています。

1. **月間シフト表**：セルのプルダウンまたはペイント入力でシフトを入れる
2. **1日チャート**：休憩の配置と、雇用区分別を含む時間帯ごとの人数を確認する
3. **印刷・転記**：A4横の月間一覧と社内システム転記一覧を出力する

画面上部の3つの大きなボタンでこの順に切り替えます。アプリ名と保存状態は固定トップバーに常時表示され、保存は自動で行われます。

マスター読込・CSV出力・バックアップなどの操作は「データの読み込み・保存」パネルに集約し、普段は折りたたんでいます。従業員が未登録の場合は、月間画面に3ステップの初回ガイドを表示します。

## ワークスペース

共用端末の同一ブラウザプロファイルで複数人が別々のシフト案を作れるよう、各シフト表をワークスペースとして分離します。

各ワークスペースには次のデータが個別に保存されます。

- 名称
- 対象月
- 従業員
- シフト定義
- 月間シフト
- 休憩配置
- 更新日時

上部の切替欄には名称、対象月、更新日時を表示します。作成者名や売場名を名称に含めると、他人の表を誤って編集する事故を減らせます。更新日時はシフトや従業員などのデータを変更したときだけ更新され、表示月の切替や閲覧だけでは変わりません。

新規作成は空の表を作り、複製は従業員・シフト・休憩を含む独立したコピーを作ります。最後に残った1件は削除できません。

### 既存データの移行

旧形式の単一シフト表が保存されている場合、初回起動時に自動的に「無題のシフト表」というワークスペースへ移行します。従業員、シフト、休憩、残業設定は維持されます。

旧形式のJSONバックアップも、復元時に同じ方法で1件のワークスペースへ移行します。

## Undo・Redo

操作履歴はワークスペースごとに分離し、ブラウザを閉じるまで最大50件をメモリ内に保持します。履歴自体はIndexedDBへ保存しないため、通常データの保存容量を圧迫しません。

履歴対象：

- シフト変更と、それに伴う休憩再配置
- 従業員の追加・編集・削除
- 当日全員の休憩再配置
- CSV・Excelマスター読込
- 月間シフトと休憩の一括クリア
- シフト表の名称・対象月変更

ワークスペースの新規作成・複製・削除、JSON復元、表示月や画面表示の切替は履歴対象外です。JSON復元後は、復元前の状態との混在を防ぐため操作履歴を初期化します。

操作方法：

- 画面の「元に戻す」「やり直す」ボタン
- `Ctrl+Z`または`⌘Z`：元に戻す
- `Ctrl+Y`または`⌘Shift+Z`：やり直す

テキスト入力欄やダイアログを操作している間は、アプリ全体のショートカットを実行しません。

## 印刷・転記

画面上部の「印刷・転記」から、次の2種類を選択できます。

### 月間シフト一覧

- A4横向きで固定
- 1か月分のシフト略称を一覧表示
- 従業員コード・所属・勤務日数・実働・残業を表示
- シフト略称と勤務時間の凡例を表示
- 従業員数が多い場合は縦方向に複数ページへ分割
- 各ページで日付見出しを繰り返す

31日分をA4横の印字領域に収めるため、画面のプルダウンではなく印刷専用のコンパクトな表を生成します。

### 社内システム転記一覧

日付順・従業員順に次の項目を表示します。

- シフト名
- 勤務時間
- 休憩時刻
- 休憩合計
- 実働時間
- 残業見込み
- 休憩ルールの確認状態

休憩が未配置、法定時間不足、勤務時間外への配置、重複などがある行は「要確認」と表示します。印刷日時とワークスペース名もヘッダーに入ります。

用紙設定はCSSの`@page`でA4横・余白8mmを指定しています。ブラウザの印刷画面で用紙サイズが上書きされている場合は、A4と横向きを確認してください。

## 休憩の自動配置と検証

休憩の法定最低時間は、休憩を差し引いた実働時間から判定します。

| 実働時間 | 必要休憩 |
| --- | ---: |
| 6時間以下 | 0分 |
| 6時間超〜8時間以下 | 45分以上 |
| 8時間超 | 60分以上 |

自動配置は次の方針です。

- 4時間以下の拘束：休憩なし
- 4時間超〜6時間15分の拘束：店舗ルールとして小休憩15分
- 6時間16分〜8時間45分の拘束：昼休憩45分
- 8時間46分〜8時間59分の拘束：昼休憩60分
- 9時間以上の拘束：小休憩15分、昼休憩60分、小休憩15分

自動配置は、従来の貪欲配置を初期解にして、シード付き乱数で決まる順序の座標降下法でスコアを最小化します。スコアは同時休憩の集中、休憩中に残る稼働人数、目標時刻からのズレを分けて評価し、同じ入力と同じシードでは同じ案を返します。`locked: true` の休憩は固定扱いになり、自動配置で変更されません。配置後は実際の休憩合計と実働時間を再計算し、法定時間の不足、勤務時間外への配置、休憩の重複を1日チャートで警告します。

既存保存データを開いた際は休憩を自動再配置しません。警告を確認し、必要な場合だけ画面の「休憩を再配置」を使用してください。シフトを個別に変更した場合は、変更した従業員の休憩だけを自動配置します。

## マスターCSV・Excel

画面の「Excel見本」から、通常シフト、従業員例、休日区分を収録した`.xlsx`を取得できます。そのまま「マスター読込」で動作確認でき、内容を書き換えて実データ用の雛形としても使えます。

見本の「マスターデータ」シートは次の形式です。

```csv
種別,コード,名称,開始時刻,終了時刻,所属,表示順,略称,固定残業時間,シフト残業時間
従業員,E001,田中太郎,,,園芸,1,,20,
従業員,E002,佐藤花子,,,資材,2,,10,
シフト,01,,06:45,16:15,,,,
シフト,02,,06:45,17:45,,,,
```

- シフトの名称が空欄でコードが入力されている場合、コードを表示名・略称として使用します
- `雇用区分`：`社員`、`準社員`、`パート・アルバイト`のいずれか（省略時はパート・アルバイト扱い）
- `固定残業時間`：従業員の月間固定残業枠
- `シフト残業時間`：そのシフトを1回割り当てたときの残業見込み
- 時間は`20`、`1.5`、`01:30`のいずれでも入力可能
- 分単位で指定する場合は`固定残業分`、`シフト残業分`も利用可能

従業員コードまたはシフトコードが既存データと一致した場合は更新します。コードが空の場合は、同じ名称を更新候補として扱います。

従業員だけ、シフトだけのCSV・Excelも読み込めます。

```csv
従業員コード,氏名,所属,表示順,固定残業時間
E001,田中太郎,園芸,1,20
```

```csv
シフトコード,シフト名,開始時刻,終了時刻,略称,シフト残業時間
01,01,06:45,16:15,01,0
休,公休,,,,休,0
```

Excelは`.xlsx`内のワークシートを確認し、「種別・コード・名称」を含むマスターデータ用シートを読み込みます。シート名に「休日区分」または「特殊シフト」を含む補助シートは、コードと名称を休日シフトとして追加します。

`Yシフト`、`シフトY`、`Jシフト`のように別コードとの組み合わせを表す行は、単独のシフト区分として登録すると勤務時間が失われるため、自動取込せず説明行として扱います。

古い`.xls`、パスワード付きファイル、複雑な数式やマクロの読み込みには対応していません。

## 残業集計

月間表では、各従業員について次を表示します。

- シフトごとの残業時間を合計した「残業見込」
- 従業員の固定残業時間から残業見込を引いた「固定残業残」
- 固定残業時間を超えた場合の「超過」表示

これはシフト案を比較するための見込み値であり、正式な給与計算や実績管理には使用しません。

## データの扱い

アプリ本体はGitHub Pagesから読み込みますが、入力した氏名やシフト案、読み込んだExcelデータはIndexedDBにだけ保存します。`fetch`や`XMLHttpRequest`などの送信処理は実装していません。

Excelの展開と解析もブラウザ内で行い、ファイル内容を外部へ送信しません。Content Security Policy（CSP）の`connect-src 'none'`も維持しています。

JSONバックアップは選択中の表だけでなく、端末内の全ワークスペースをまとめて出力・復元します。ブラウザの閲覧データを削除すると保存内容も消えるため、定期的にバックアップしてください。

## GitHub Pages

公開URL：

```text
https://shinbowork2025-ops.github.io/shift-assistant/
```

`main`ブランチの`/(root)`をGitHub Pagesで公開します。ビルドコマンドは不要です。

### 更新の反映について

GitHub Pagesは各ファイルを最大10分キャッシュします（`Cache-Control: max-age=600`）。更新直後は新旧のファイルが混在し、表示が崩れたり動かなくなったりすることがあります。この状態を検知すると画面上部に再読み込みの案内が表示されます。数分待ってから再読み込み（`Ctrl+F5`または`⌘Shift+R`のスーパーリロード）してください。
