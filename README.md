# Shift Assistant

店舗PCのブラウザだけで動作する、社内システム登録前のシフト編成支援ツールです。正式な勤怠記録やシフト確定は社内システムで行います。

## 設計方針

- 静的なHTML・CSS・JavaScriptのみで動作
- 入力データはブラウザ内のIndexedDBに保存
- シフトデータを外部サーバーへ送信しない
- JavaScript Object Notation（JSON）で全シフト表をバックアップ・復元
- CSVまたはExcel（`.xlsx`）でマスター読込
- CSVでシフト案を出力
- ビルド処理や外部ライブラリを使わない

## 主な機能

- 複数のシフト表を作成・切替・複製・削除
- シフト表ごとに名称、対象月、更新日時を表示
- 従業員の追加・編集・削除
- CSV・Excelによる従業員、シフト、残業設定の登録と更新
- 任意のシフト名、開始時刻、終了時刻の利用
- シフトごとの残業見込み時間
- 従業員ごとの月間固定残業時間
- 月間の残業見込み、固定残業残時間、超過見込みの表示
- 月間シフト案の入力
- 日付を押して1日単位の時間帯チャートを表示
- 休憩を除いた15分単位の実配置人数表示
- シフト変更後の休憩自動配置
- 休憩の法定基準検証と警告表示
- 従業員別の勤務日数・実働時間集計
- IndexedDBへの自動保存
- シフト案のCSV出力
- 全シフト表のJSONバックアップ・復元

## ワークスペース

共用端末の同一ブラウザプロファイルで複数人が別々のシフト案を作れるよう、各シフト表をワークスペースとして分離します。

各ワークスペースには次のデータが個別に保存されます。

- 名称
- 対象月
- 従業員
- シフト定義
- 月間シフト
- 休憩配置
- 更新日時

上部の切替欄には名称、対象月、更新日時を表示します。作成者名や売場名を名称に含めると、他人の表を誤って編集する事故を減らせます。

新規作成は空の表を作り、複製は従業員・シフト・休憩を含む独立したコピーを作ります。最後に残った1件は削除できません。

### 既存データの移行

旧形式の単一シフト表が保存されている場合、初回起動時に自動的に「無題のシフト表」というワークスペースへ移行します。従業員、シフト、休憩、残業設定は維持されます。

旧形式のJSONバックアップも、復元時に同じ方法で1件のワークスペースへ移行します。

## 休憩の自動配置と検証

休憩の法定最低時間は、休憩を差し引いた実働時間から判定します。

| 実働時間 | 必要休憩 |
| --- | ---: |
| 6時間以下 | 0分 |
| 6時間超〜8時間以下 | 45分以上 |
| 8時間超 | 60分以上 |

自動配置は次の方針です。

- 4時間以下の拘束：休憩なし
- 4時間超〜6時間15分の拘束：店舗ルールとして小休憩15分
- 6時間16分〜8時間45分の拘束：昼休憩45分
- 8時間46分〜8時間59分の拘束：昼休憩60分
- 9時間以上の拘束：小休憩15分、昼休憩60分、小休憩15分

同時に休憩する人数が少なくなる候補を優先します。配置後は実際の休憩合計と実働時間を再計算し、法定時間の不足、勤務時間外への配置、休憩の重複を1日チャートで警告します。

既存保存データを開いた際は休憩を自動再配置しません。警告を確認し、必要な場合だけ画面の「休憩を再配置」を使用してください。シフトを個別に変更した場合は、変更した従業員の休憩だけを自動配置します。

## マスターCSV・Excel

画面の「CSV見本」から雛形を取得できます。雛形をExcelで開いて編集し、`.xlsx`として保存したファイルも、そのまま「マスター読込」から読み込めます。

```csv
種別,コード,名称,開始時刻,終了時刻,所属,表示順,略称,固定残業時間,シフト残業時間
従業員,E001,田中太郎,,,園芸,1,,20,
従業員,E002,佐藤花子,,,資材,2,,10,
シフト,S01,早番,09:00,18:00,,,早,,1
シフト,S02,遅番,12:00,21:00,,,遅,,0.5
シフト,OFF,公休,,,,,休,,0
```

- `固定残業時間`：従業員の月間固定残業枠
- `シフト残業時間`：そのシフトを1回割り当てたときの残業見込み
- 時間は`20`、`1.5`、`01:30`のいずれでも入力可能
- 分単位で指定する場合は`固定残業分`、`シフト残業分`も利用可能

従業員コードまたはシフトコードが既存データと一致した場合は更新します。コードが空の場合は、同じ名称を更新候補として扱います。

従業員だけ、シフトだけのCSV・Excelも読み込めます。

```csv
従業員コード,氏名,所属,表示順,固定残業時間
E001,田中太郎,園芸,1,20
```

```csv
シフトコード,シフト名,開始時刻,終了時刻,略称,シフト残業時間
S01,早番,09:00,18:00,早,1
```

Excelは`.xlsx`の先頭シートを読み込みます。古い`.xls`、パスワード付きファイル、複雑な数式やマクロの読み込みには対応していません。

## 残業集計

月間表では、各従業員について次を表示します。

- シフトごとの残業時間を合計した「残業見込」
- 従業員の固定残業時間から残業見込を引いた「固定残業残」
- 固定残業時間を超えた場合の「超過」表示

これはシフト案を比較するための見込み値であり、正式な給与計算や実績管理には使用しません。

## データの扱い

アプリ本体はGitHub Pagesから読み込みますが、入力した氏名やシフト案、読み込んだExcelデータはIndexedDBにだけ保存します。`fetch`や`XMLHttpRequest`などの送信処理は実装していません。

Excelの展開と解析もブラウザ内で行い、ファイル内容を外部へ送信しません。Content Security Policy（CSP）の`connect-src 'none'`も維持しています。

JSONバックアップは選択中の表だけでなく、端末内の全ワークスペースをまとめて出力・復元します。ブラウザの閲覧データを削除すると保存内容も消えるため、定期的にバックアップしてください。
