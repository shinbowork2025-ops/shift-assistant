# Shift Assistant

店舗PCのブラウザだけで動作する、社内システム登録前のシフト編成支援ツールです。正式な勤怠記録やシフト確定は社内システムで行います。

## 設計方針

- 静的なHTML・CSS・JavaScriptのみで動作
- 入力データはブラウザ内のIndexedDBに保存
- シフトデータを外部サーバーへ送信しない
- JavaScript Object Notation（JSON）でバックアップ・復元
- CSVまたはExcel（`.xlsx`）でマスター読込
- CSVでシフト案を出力
- ビルド処理や外部ライブラリを使わない

## 主な機能

- 従業員の追加・編集・削除
- CSV・Excelによる従業員、シフト、残業設定の登録と更新
- 任意のシフト名、開始時刻、終了時刻の利用
- シフトごとの残業見込み時間
- 従業員ごとの月間固定残業時間
- 月間の残業見込み、固定残業残時間、超過見込みの表示
- 月間シフト案の入力
- 日付を押して1日単位の時間帯チャートを表示
- 休憩を除いた15分単位の実配置人数表示
- シフト変更後の休憩自動配置
- 従業員別の勤務日数・実働時間集計
- IndexedDBへの自動保存
- シフト案のCSV出力
- JSONバックアップ・復元

## 休憩の自動配置

8時間以上の勤務には次の休憩を、おおむね2時間間隔で割り当てます。

- 小休憩15分
- 昼休憩60分
- 小休憩15分

同時に休憩する人数が少なくなる候補を優先します。4時間以上8時間未満の勤務には、小休憩15分を1回割り当てます。

これは初期版の簡易配置です。必要人数、売場、資格者などの条件はまだ判定しません。

## マスターCSV・Excel

画面の「CSV見本」から雛形を取得できます。雛形をExcelで開いて編集し、`.xlsx`として保存したファイルも、そのまま「マスター読込」から読み込めます。

```csv
種別,コード,名称,開始時刻,終了時刻,所属,表示順,略称,固定残業時間,シフト残業時間
従業員,E001,田中太郎,,,園芸,1,,20,
従業員,E002,佐藤花子,,,資材,2,,10,
シフト,S01,早番,09:00,18:00,,,早,,1
シフト,S02,遅番,12:00,21:00,,,遅,,0.5
シフト,OFF,公休,,,,,休,,0
```

- `固定残業時間`：従業員の月間固定残業枠
- `シフト残業時間`：そのシフトを1回割り当てたときの残業見込み
- 時間は`20`、`1.5`、`01:30`のいずれでも入力可能
- 分単位で指定する場合は`固定残業分`、`シフト残業分`も利用可能

従業員コードまたはシフトコードが既存データと一致した場合は更新します。コードが空の場合は、同じ名称を更新候補として扱います。

従業員だけ、シフトだけのCSV・Excelも読み込めます。

```csv
従業員コード,氏名,所属,表示順,固定残業時間
E001,田中太郎,園芸,1,20
```

```csv
シフトコード,シフト名,開始時刻,終了時刻,略称,シフト残業時間
S01,早番,09:00,18:00,早,1
```

Excelは`.xlsx`の先頭シートを読み込みます。古い`.xls`、パスワード付きファイル、複雑な数式やマクロの読み込みには対応していません。

## 残業集計

月間表では、各従業員について次を表示します。

- シフトごとの残業時間を合計した「残業見込」
- 従業員の固定残業時間から残業見込を引いた「固定残業残」
- 固定残業時間を超えた場合の「超過」表示

これはシフト案を比較するための見込み値であり、正式な給与計算や実績管理には使用しません。

## データの扱い

アプリ本体はGitHub Pagesから読み込みますが、入力した氏名やシフト案、読み込んだExcelデータはIndexedDBにだけ保存します。`fetch`や`XMLHttpRequest`などの送信処理は実装していません。

Excelの展開と解析もブラウザ内で行い、ファイル内容を外部へ送信しません。Content Security Policy（CSP）の`connect-src 'none'`も維持しています。

ブラウザの閲覧データを削除すると保存内容も消えるため、定期的にJSONバックアップを作成してください。同じURLでも、別のPC・別のブラウザ・別のブラウザ利用者の保存領域とは共有されません。
