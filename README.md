# Shift Assistant

店舗PCのブラウザだけで動作する、社内システム登録前のシフト編成支援ツールです。正式な勤怠記録やシフト確定は社内システムで行います。

## 設計方針

- 静的なHTML・CSS・JavaScriptだけで動作
- 入力データはブラウザ内のIndexedDBに保存
- シフトデータを外部サーバーへ送信しない
- JavaScript Object Notation（JSON）形式で全シフト表をバックアップ・復元
- Comma-Separated Values（CSV）またはExcel（`.xlsx`）でマスターを読込
- CSVでシフト案を出力
- ビルド処理や配信用の外部ライブラリを使わない

## 主な機能

- 複数のシフト表を作成・切替・複製・削除
- 従業員、雇用区分、所属、資格、勤務可能シフトの管理
- 月間シフト表のプルダウン入力、ペイント入力、希望休、セルロック
- 通常入力・シフト入力・セルロック・希望休をまとめた編集モード欄
- 月間表のコンパクト表示
- 従業員の複数選択による表示絞り込み
- 15分単位の1日チャート
- 休憩の自動配置、手動編集、自動再配置からの保護
- 合計人数、雇用区分、部門、資格者を含む必要人数設定
- 月間の勤務日数、実働時間、残業見込み、固定残業残の集計
- 月間ソルバーによる公休・勤務シフトの自動作成と改善
- 月間の要確認一覧
- A4横の月間表と社内システム転記一覧
- ワークスペース別のUndo・Redo
- IndexedDBへの自動保存、別タブ競合検出、バックアップ経過表示

## 基本的な作業手順

1. ExcelまたはCSVから従業員とシフト区分を登録する
2. 従業員ごとに休み方、勤務可能シフト、優先シフトを設定する
3. 必要人数、必要部門、必要資格を設定する
4. 希望休や確定済みセルを入力してロックする
5. 月間ソルバーで案を作成する
6. 変更内容と不足・違反を確認して適用する
7. 1日チャートで休憩と配置人数を確認する
8. 月間の要確認一覧が「転記準備OK」になったことを確認する
9. 印刷または転記一覧を使って社内システムへ登録する

## 月間表の編集モード

月間表上部の「編集モード」から操作方法を切り替えます。

- **通常入力**：セルのプルダウンで1件ずつ入力
- **シフト入力**：選択したシフトをクリックまたはドラッグで連続入力
- **セルロック**：自動作成で変更しないセルをロックまたは解除
- **希望休**：希望休を登録または解除

`Esc`キーで通常入力へ戻れます。

## 月間表の表示設定

- **コンパクト表示**：セル幅、高さ、従業員情報を縮小して1画面の表示量を増やします
- **従業員を絞り込む**：複数の従業員を選んで月間表の行だけを表示します

絞り込みは画面表示だけに作用し、集計、印刷、月間ソルバーの対象は変更しません。

## 月間ソルバー

月間ソルバーは、最初に公休と勤務シフトの初期案を作成し、その後に月全体を反復改善します。

評価順は次のとおりです。

1. 必要人数、雇用区分、部門、資格者の不足
2. 11時間未満の勤務間隔と連続勤務上限
3. 固定残業枠の超過
4. 休日数、土日勤務、遅番回数、シフト種別の偏り
5. 優先シフトと既存シフトの傾向

### 実行方法

- **高速**：短時間で案を確認するための設定
- **標準**：通常の月間作成で推奨する設定
- **精密**：最大3分間、異なる乱数条件で独立探索を繰り返し、その時間内で最も良い案を表示

精密実行でも全体最適解は保証しません。画面を固めないようWeb Workerで実行し、途中で中断した場合はその時点までの最良案を返します。

### 休日数の扱い

月間ソルバーは、初期案を作成した後の探索中に従業員ごとの休日数を増減しません。休日の位置は移動できますが、勤務日と休日の単純な置換は行いません。

初期案の時点で、ロックや既存休日のために目標休日数を満たせない場合は、案を適用できません。

### 案を適用できる条件

次をすべて満たした案だけ適用できます。

- 固定セルと使用可能シフト区分に矛盾がない
- 従業員ごとの休日数が目標と一致する
- 11時間未満の勤務間隔がない
- 連続勤務上限を超えていない
- 必要人数、雇用区分、部門、資格者の不足がない
- 探索後に対象セルが新しくロックされていない

条件を満たさない案は結果を確認できますが、「この案を適用」ボタンを表示しません。

## 休憩の自動配置と検証

休憩の法定最低時間は、休憩を差し引いた実働時間から判定します。

| 実働時間 | 必要休憩 |
| --- | ---: |
| 6時間以下 | 0分 |
| 6時間超〜8時間以下 | 45分以上 |
| 8時間超 | 60分以上 |

自動配置の基本設定は次のとおりです。

- 4時間以下の拘束：休憩なし
- 4時間超〜5時間の拘束：小休憩15分
- 5時間超〜8時間45分の拘束：昼休憩45分
- 8時間46分〜8時間59分の拘束：昼休憩60分
- 9時間以上の拘束：小休憩15分、昼休憩60分、小休憩15分

配置時刻は、休憩を除いた実配置人数が手薄になる時間を減らすよう日全体で調整します。

## 必要人数の設定

1日チャートの「必要人数を設定」から、時間帯ごとに次を登録できます。

- 適用曜日：毎日、平日、土日
- 開始時刻、終了時刻
- 合計人数
- 社員、準社員、パート・アルバイト別の最小人数
- 必要部門と部門人数
- 必要資格と資格者人数

設定はブラウザ画面または配置条件CSVから登録できます。

## マスターCSV・Excel

「Excel見本」から、通常シフト、従業員例、休日区分を収録した`.xlsx`を取得できます。

基本形式：

```csv
種別,コード,名称,開始時刻,終了時刻,所属,表示順,略称,固定残業時間,シフト残業時間
従業員,E001,田中太郎,,,園芸,1,,20,
シフト,01,,06:45,16:15,,,,0
```

- `雇用区分`：`社員`、`準社員`、`パート・アルバイト`
- `固定残業時間`：従業員の月間固定残業枠
- `シフト残業時間`：そのシフトを1回割り当てたときの残業見込み
- 時間は`20`、`1.5`、`01:30`の形式を利用可能
- 古い`.xls`、パスワード付きファイル、複雑な数式やマクロには未対応

## 保存とバックアップ

入力内容はIndexedDBへ自動保存します。

- 保存ごとにリビジョン番号を付け、別タブからの古い上書きを拒否
- 別タブの更新を検知した場合は再読み込み案内を表示
- ブラウザが対応している場合は永続ストレージを要求
- JSONバックアップの最終作成日時を表示
- 7日以上バックアップがない場合は注意表示

ブラウザの閲覧データを削除すると保存内容も消えるため、定期的にJSONバックアップを作成してください。

## 印刷・転記

### 月間シフト一覧

- A4横向き
- 1か月分のシフト略称
- 従業員コード、所属、勤務日数、実働、残業
- 従業員数が多い場合は縦方向に複数ページへ分割

### 社内システム転記一覧

日付順、従業員順に次を表示します。

- シフト名と勤務時間
- 休憩時刻と休憩合計
- 実働時間
- 残業見込み
- 休憩ルールの確認状態
