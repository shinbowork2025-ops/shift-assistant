# 公休の半自動配置

月間シフトでは、従業員ごとの休み方を基準に公休を自動配置できます。人が入力してロックしたセルは変更しません。

## 従業員設定

従業員名を押して編集画面を開き、「公休の自動配置設定」を入力します。

### 休み方

- 自動配置しない
- 5勤2休
- 3勤1休
- 2勤1休
- 3勤1休＋2勤1休
- 4勤1休＋4勤2休
- 週2休・分散

既存従業員は「自動配置しない」で読み込まれます。休み方を設定するまで、自動配置の対象にはなりません。

### 月間公休日数

0の場合は休み方パターンから自動計算します。数値を指定した場合は、有休など既存の休日区分を含めた月間休日数として扱います。

### パターン開始位置

「自動」を選ぶと従業員の表示順で周期をずらし、全員の公休が同じ日に重なることを抑えます。手動で0〜10日ずらすこともできます。

### 固定休曜日

指定した曜日を公休候補として優先します。ロック済みの勤務と重なる場合は、ロックを維持して警告します。

## 配置手順

1. 人が確定したシフトや空欄をロックします。
2. 「公休を自動配置」を押します。
3. 配置する休日区分を選びます。
4. 配置モードを選びます。
5. 従業員別の休日数・最大連勤・警告を確認します。
6. 「この内容で配置」を押します。

自動配置全体はUndo 1回で元に戻せます。

## 配置モード

### 空欄だけに公休を入れる

安全側の既定モードです。

- ロック済みセルを維持
- 入力済み勤務を維持
- 入力済み公休を維持
- 有休など他の休日区分を維持
- 空欄だけへ公休を追加

### 未ロックの公休を再配置する

公休の並びを組み直すモードです。

- ロック済みセルを維持
- 有休など公休以外の休日区分を維持
- 未ロックの既存公休を解除・再配置
- 空欄が優先される
- 空欄だけでは不足する場合、未ロックの勤務を公休へ変更できる

## 配置の優先順位

1. 固定休曜日
2. 休み方パターン上の休日
3. 日ごとの公休人数が少ない日
4. 既存勤務を上書きしない候補
5. パターンに近い代替日

完全に条件を満たせない場合は、無理にロックを解除せず警告を表示します。

## 警告

次の状態を警告します。

- 休み方が未設定
- パターン上の休日がロック済み
- 配置可能なセルが不足
- 有休など既存休日が目標日数を超過
- 固定休曜日数が月間公休日数を超過
- 月内の最大連勤がパターン目安を超過

最大連勤は、未入力の非休日セルを勤務予定として数えた参考値です。月をまたぐ連勤判定は今後の拡張対象です。

## 自動編成との関係

この機能は公休だけを配置します。早番・遅番など勤務シフトの自動割当は行いません。

次の段階では、ここで配置した公休とロックを固定条件として、未ロックの勤務日にシフトコードを割り当てます。
