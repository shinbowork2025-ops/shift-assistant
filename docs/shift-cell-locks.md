# シフトセルのロック

月間シフト表では、人が確定した勤務や、自動編成へ触らせたくない空欄セルをロックできます。

## 個別操作

各セル右上の四角ボタンを押すと、ロックと解除を切り替えます。

- 塗りつぶされた四角：ロック済み
- 空の四角：未ロック

ロック済みセルは月間表と1日チャートのプルダウンから変更できません。

## 一括操作

月間表上部の「セルロック」から次を選択します。

- ロックを塗る
- 解除を塗る
- 通常入力に戻す

ロックまたは解除を選んだ状態でセルをクリック・ドラッグすると、複数セルをまとめて変更できます。1回のドラッグ全体がUndo／Redoの1操作になります。

## 空欄セルのロック

シフトが未入力のセルもロックできます。これは「自動編成でも埋めない」という指定に使います。

## シフトペイントとの関係

シフトペイントとロックペイントは排他的です。ロック済みセルをシフトペイントで通過した場合、そのセルは変更せず、スキップ数を操作結果へ表示します。

## 保存と出力

ロック状態はワークスペース内の`shiftLocks`へ保存します。

- IndexedDB保存
- JSONバックアップ・復元
- ワークスペース複製
- Undo／Redo

には含まれます。

ロックは編集用の情報なので、月間印刷、転記一覧、シフトCSVには出力しません。

## 自動編成からの利用

自動編成や再調整でシフトを変更する場合は、`setShift()`へ`respectLock: true`を指定します。

```js
const changed = setShift(employeeId, day, shiftCode, {
  save: false,
  respectLock: true
});
```

ロック済みの場合は`false`を返し、シフトと休憩を変更しません。自動編成側はロック済みセルを固定条件として扱い、未ロックセルだけを候補にしてください。

## 削除

- 従業員を削除すると、その従業員の全ロックも削除します
- 月間クリアでは、その月のシフト・休憩・ロックをまとめて削除します
