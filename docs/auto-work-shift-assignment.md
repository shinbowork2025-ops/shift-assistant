# 勤務シフトの自動割当

公休・有休などの休日区分を配置したあと、未ロックの勤務日へ早番・中番・遅番などを自動割当できます。

## 事前設定

従業員名を押して編集画面を開き、「勤務シフトの自動割当設定」を入力します。

### 使用可能な勤務シフト

その従業員へ割当可能な勤務シフトを選びます。最低1種類が必要です。

- 全て許可した場合は「制限なし」として保存
- 一部だけ許可した場合は、そのシフトだけを候補にする
- 勤務時間が未設定のシフトや休日区分は候補にしない

### 優先シフト

本人が主に担当するシフトを指定できます。優先シフトは固定条件ではありません。時間帯の偏り、勤務間隔、固定残業枠との兼ね合いで別のシフトを割り当てる場合があります。

### 遅番翌日の早番回避

有効にすると、前日の終了から翌日の開始まで11時間未満となる候補へ大きなペナルティを付けます。全候補が条件を満たさない場合は、割当を続行して警告します。

## 実行手順

1. 公休・有休などの休日区分を配置します。
2. 人が確定した勤務や空欄をロックします。
3. 「勤務を自動割当」を押します。
4. 今回使う勤務シフトを選びます。
5. 割当モードを選びます。
6. 従業員別の候補数、残業見込み、警告を確認します。
7. 「この内容で割当」を押します。
8. 1日チャートで時間帯配置と休憩を確認します。

自動割当全体はUndo 1回で元に戻せます。

## 割当モード

### 空欄だけに勤務シフトを入れる

安全側の既定モードです。

- ロック済みセルを維持
- 入力済み勤務を維持
- 公休・有休などの休日区分を維持
- 空欄だけを割当対象にする

### 未ロックの勤務シフトを再割当する

勤務シフトの並びを組み直すモードです。

- ロック済みセルを維持
- 公休・有休などの休日区分を維持
- 未ロックの入力済み勤務と空欄を対象にする
- 同じシフトが最適なら変更しない

## 割当時の評価

候補の少ない従業員から処理し、次を点数化して最も低い候補を選びます。

- 従業員ごとの使用可能シフト
- 優先シフト
- 既存月間シフトの傾向
- 同じ日に同一シフトへ集中していないか
- 15分単位の時間帯配置人数が偏っていないか
- 前後日と同じシフトを継続できるか
- 前後日の勤務間隔が11時間未満にならないか
- シフトごとの残業見込み
- 固定残業枠を超過しないか

ロック済みセルは採点対象ではなく固定条件です。自動割当がロックを解除することはありません。

## 警告

次の状態を警告します。

- 使用可能なシフトと今回の候補が一致しない
- 対象セルへ割当できない
- 前後日の勤務間隔が11時間未満
- 残業見込みが固定残業枠を超過

警告があってもロックや休日区分は変更しません。

## 休憩

適用時は、変更した日と従業員だけ休憩を再計算します。変更していないセルの休憩には触れません。

## 現在の限界

この版は勤務時間帯を均等化するヒューリスティックです。次の条件はまだ最適化していません。

- 時間帯ごとの必要人数（例：17時に最低3人）
- 部門・売場ごとの必要人数
- 特定資格者や開錠担当者の必須配置
- 前月末・翌月初を含む勤務間隔と連勤
- 希望勤務シフトの日付指定
- 数学的な全体最適解の探索

したがって、自動割当後は必ず1日チャートと警告を確認し、必要なセルを人が修正・ロックしてください。
