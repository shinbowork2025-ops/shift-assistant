# シフト作成補助ツール 説明用資料

店舗PCのブラウザ上で、月間シフト案の作成・確認・印刷を支援するツールです。

> 正式なシフト確定・勤怠記録は、従来どおり社内システムで行います。

## 1. 導入目的

- シフト作成時の手入力、人数確認、休憩配置、集計、転記前確認を一つの画面にまとめる
- 必要人数・資格者・部門配置などの不足を、作成途中で確認できるようにする
- 自動作成は最終決定ではなく、担当者が確認・修正するための案を作る
- 社内システムへの登録前に、見落としや入力漏れを減らす

## 2. 主な機能

| 機能 | 内容 |
| --- | --- |
| 月間シフト編集 | プルダウン入力、連続入力、希望休、確定セルのロック、従業員の絞り込み |
| 必要人数の確認 | 時間帯ごとに、合計人数、雇用区分、部門、資格者の必要数を設定し、不足を表示 |
| 月間シフト案の自動作成 | 休日数、勤務間隔、連続勤務、残業見込み、偏りなどを考慮して案を作成 |
| 休憩の自動配置 | 法定休憩を確認し、始業・終業直前や人員が手薄な時間を避けて配置 |
| 要確認一覧 | 未入力とその他の問題を分け、転記前に確認すべき項目を一覧化 |
| 集計・印刷 | 勤務日数、実働時間、残業見込みを集計し、A4月間表と転記一覧を出力 |

## 3. 基本的な使用手順

1. ExcelまたはComma-Separated Values（CSV）ファイルから、従業員とシフト区分を登録する
2. 勤務可能シフト、休み方、必要人数、必要資格などを設定する
3. 希望休や変更しないセルを入力・ロックする
4. 月間シフト案を自動作成し、不足・違反・変更内容を確認する
5. 必要に応じて手直しし、1日ごとの休憩と配置人数を確認する
6. 月間表または転記一覧を印刷し、社内システムへ登録する

## 4. 自動作成で優先する条件

自動作成は、次の順番を重視してシフト案を改善します。

| 優先 | 確認項目 | 内容 |
| ---: | --- | --- |
| 1 | 必要人数 | 合計人数、雇用区分、部門、資格者の不足をなくす |
| 2 | 勤務上の制約 | 勤務間隔11時間未満と、連続勤務上限超過を防ぐ |
| 3 | 残業 | 固定残業枠の超過を減らす |
| 4 | 偏り | 休日数、土日勤務、遅番回数、シフト種別の偏りを減らす |
| 5 | 希望・既存傾向 | 優先シフトや、すでに入力された傾向をできるだけ尊重する |

## 5. データの扱い

- 入力したシフトデータは、店舗PCのブラウザ内に保存する
- シフトデータを外部サーバーへ送信しない
- 別タブからの古い上書きを検知し、競合を防ぐ
- JavaScript Object Notation（JSON）形式でバックアップを作成・復元できる

## 6. 運用上の注意

- 本ツールはシフト編成の補助であり、正式な勤務命令・勤怠記録・給与計算には使用しない
- 自動作成は条件を満たす案を探索するもので、唯一の最適解を保証しない
- 必要人数や資格条件などの設定が誤っている場合、結果も正しくならないため、初期設定の確認が必要
- ブラウザの閲覧データを削除すると保存内容も消えるため、定期的なバックアップが必要
- 最終的なシフト内容は担当者が確認し、社内ルールと実際の勤務条件に照らして判断する

## 7. 想定される作業上の変化

| 現状の作業 | ツール使用後 |
| --- | --- |
| 人数不足を日ごと・時間帯ごとに目視確認 | 不足時間帯を画面上で表示 |
| 休憩を個別に配置して重なりを確認 | 条件に沿って自動配置し、必要箇所だけ修正 |
| 勤務日数・実働・残業を別途集計 | 月間表から自動集計 |
| 転記前に複数箇所を確認 | 未入力と問題項目を一覧で確認 |
